# Подсчёт транспорта с камеры видеонаблюдения

Приложение для Windows. Подключается к IP-камере (RTSP), USB-камере или видеофайлу,
распознаёт транспорт нейросетью YOLO и считает машины, пересёкшие линию подсчёта,
**отдельно по типам**:

| Тип | Класс нейросети |
|---|---|
| Легковые | `car` |
| Грузовики | `truck` |
| Автобусы | `bus` |
| Мотоциклы (можно скрыть) | `motorcycle` |

Каждая машина получает свой ID (трекер ByteTrack) и считается **один раз**. Тип выбирается
голосованием по всем кадрам, поэтому если нейросеть на одном кадре спутала грузовик с легковой,
на итог это не повлияет. Учитываются оба направления движения (↓ и ↑).

## Установка

1. Установите **Python 3.10–3.12** с [python.org](https://www.python.org/downloads/)
   (при установке отметьте **Add Python to PATH**).
2. Запустите `install.bat`. Если есть видеокарта NVIDIA, ответьте `y`: с ней обработка быстрее в 5–20 раз.
3. Запуск: `run.bat`.

### Сборка .exe (по желанию)
`build_exe.bat` создаст папку `dist\VehicleCounter` с `VehicleCounter.exe`. Эту папку можно
скопировать на другой компьютер, Python там не нужен. Папка весит 1–3 ГБ, большую часть занимает PyTorch.

## Работа

1. Введите адрес камеры в поле «Камера / источник» и нажмите **▶ Старт**.
2. Нажмите **«Задать линию подсчёта»** и кликните по видео две точки. Линию проводите **поперёк**
   дороги там, где машины хорошо видны и не перекрывают друг друга. Пока линия не задана,
   стоит горизонтальная линия на 60 % высоты кадра.
3. Счётчики обновляются справа. Каждый проезд записывается в `logs\проезды_ГГГГ-ММ-ДД.csv`
   (открывается в Excel). Кнопка «Экспорт итогов» сохраняет сводную таблицу.

Настройки (адрес, модель, линия) сохраняются в `config.json` и подставляются при следующем запуске.

### Адреса RTSP популярных камер
| Производитель | Адрес |
|---|---|
| Hikvision | `rtsp://логин:пароль@IP:554/Streaming/Channels/101` (102 — дополнительный поток) |
| Dahua / Imou | `rtsp://логин:пароль@IP:554/cam/realmonitor?channel=1&subtype=0` |
| Uniview | `rtsp://логин:пароль@IP:554/unicast/c1/s0/live` |
| TP-Link Tapo/VIGI | `rtsp://логин:пароль@IP:554/stream1` |
| Trassir, RVi, Polyvision, XMeye | смотрите в настройках камеры или в программе ONVIF Device Manager |
| USB-камера | `0` (или `1`, `2`…) |
| Видеофайл | кнопка «Файл…» |

Если в пароле есть спецсимволы (`@`, `#`, `:`), замените их кодами: `@` → `%40`, `#` → `%23`, `:` → `%3A`.

## Выбор модели и скорость

| Модель | Точность | Без видеокарты (CPU) | С видеокартой NVIDIA |
|---|---|---|---|
| `yolo11n.pt` | базовая | ~10–20 кадр/с | 100+ |
| `yolo11s.pt` (по умолчанию) | хорошая | ~5–10 кадр/с | 80+ |
| `yolo11m.pt` | высокая | ~2–4 кадр/с | 50+ |

Скорость указана примерно. Если обработка не успевает за камерой, лишние кадры пропускаются,
поэтому задержки не будет, но при очень низком FPS быстрые машины могут «перепрыгнуть» линию.
Чтобы этого не было:
- на слабом компьютере берите `yolo11n.pt` и **дополнительный поток** камеры (у Hikvision `…/102`);
- держите скорость обработки **не ниже 8–10 кадров/с**.

Модели скачиваются автоматически при первом запуске, нужен интернет.

## Точность: что важно знать

- Пикапы и большие фургоны нейросеть иногда относит к `truck`, микроавтобусы (Газель) бывают и `car`, и `bus`.
  Для точного разделения по вашим категориям модель нужно дообучить на кадрах с вашей камеры.
- Порог уверенности по умолчанию 0.35. Если машины пропускаются, уменьшите его; если появляются ложные срабатывания, увеличьте.
- Ночью и в сильный дождь точность падает. Камера должна смотреть на дорогу сверху и под углом, а не строго сбоку.

## Файлы
- `app.py`: интерфейс, захват видео, распознавание
- `counter.py`: логика подсчёта по линии (без зависимостей)
- `test_counter.py`: тесты логики подсчёта (`python test_counter.py`)
